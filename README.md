# avialog-insta-media

Visuels et outils de publication Instagram de @avia.log.

- `tools/render.py` : génère posts et carrousels 1080×1350 depuis un JSON (charte Avialog).
- `tools/render_reel.py` : rend un Reel HTML animé en MP4 1080×1920.
- `tools/sound_reel.py` : habillage sonore original synthétisé, libre de droits.
- `media/` : visuels publiés (servis publiquement pour Metricool).
- `data/journal.csv` : journal de performance, mis à jour par la tâche quotidienne.
- `data/plan.json` : calendrier et banque de sujets.
